Archoleat builds open-source tools for developers working with TypeScript,
React, and Next.js.

The projects address recurring frontend tasks: setting up an application,
maintaining consistent configuration, building interface components,
and preparing packages for publication. Shared tools keep those decisions
reusable across projects instead of being copied and maintained separately.

## Our approach

Each package has a focused purpose. Configuration helpers add types and editor
completion to existing tools; shared configurations capture conventions;
components and utilities can be adopted individually.

Project templates bring those pieces together with checks, builds, and release
workflows. They provide a starting point that developers can adapt to their own
requirements.

## Contributing

Bug reports, corrections, and proposals are welcome in the relevant project's
Issues. For code changes, start with the [contribution guide][contributing].
Report vulnerabilities privately using the [security policy][security].
