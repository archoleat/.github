Archoleat maintains TypeScript libraries, frontend configuration helpers,
and project templates.

| Project                     | Purpose                                     |
| --------------------------- | ------------------------------------------- |
| [Accordion][accordion]      | Animated React accordion.                   |
| [Stylelint config][scss]    | SCSS linting, BEM naming, property order.   |
| [Commitlint][commitlint]    | Typed Commitlint configuration.             |
| [Next.js config][next]      | Typed Next.js configuration.                |
| [Prettier config][prettier] | Typed Prettier configuration.               |
| [Release config][release]   | Typed semantic-release configuration.       |
| [Reglib][reglib]            | Composable regular-expression fragments.    |
| [Slugger][slugger]          | Russian Cyrillic transliteration and slugs. |
| [Font names][font]          | Font filename validation.                   |
| [Notifier][notifier]        | Console and desktop notifications.          |

Configuration helpers provide types and editor completion;
they do not validate configuration at runtime.

## Templates and shared configuration

- [next-template][next-template]: Next.js application starter.

- [npm-template][npm-template]: TypeScript package starter with Rollup, tests,
  and semantic-release.

- [.helpers][helpers]: Git and VS Code configuration templates and reusable
  GitHub rulesets.
